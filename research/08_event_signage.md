## 0. エグゼクティブサマリー

1. **数値で語れる街ぐるみイベントは「回遊×ゲーム化」と「季節×夜」の2系統です。** ポケモンGO（鳥取砂丘：約8.9万人、経済効果 約18億円）、ピカチュウ大量発生チュウ!（みなとみらい：1週間で200万人超）、赤レンガのクリスマスマーケット（2024年：約124万人／34日間）、ヨルノヨ（延べ100万人）が例です。いずれも元町から徒歩圏の「横浜の大型集客」で、**元町はこの人の流れを受け止める“回遊先”になる**のが現実的な勝ち筋です。
2. **元町通りは街づくり協定の対象で、屋外広告物の設置・取替えには届出と事前協議が必要です。** 路上に常設する大型LEDは景観面のハードルが高いと考えられます。サイネージは次の3層で考えるのが妥当です。
   - (a) 駅：元町・中華街駅のホームドアビジョン32面、地下通路
   - (b) 店頭の屋内ウィンドウ（小型・低輝度）
   - (c) 期間限定の仮設
3. **役割分担の案**：提案者は「Web/SNS/取材＝常時の発信と効果測定」、代理店は「イベント制作/OOH＝ピークの山づくり」を担います。KPIとタグ（UTM・QR）は共通設計にし、効果を一本で追える形にします。
4. **チャーミングセール（毎年30万人以上とされる／2012年時点の報道）は「セール」から「街の文化祭」へ。** 歩行者天国という既存の資産に、夜・アート・デジタル回遊を足します。

- 「数十万〜百万人級」の動員は、キャラクター/IPか、大型の季節イベントによるものです。単独の商店街で再現するのは難しいため、**横浜の大型イベントと会期を合わせ、元町を回遊先に組み込む**のが最も費用対効果の高い方法です。

**元町向け「景観配慮型」設計原則（提案）**

1. 路上の常設大型LEDは原則つくりません。**店舗ウィンドウ内側の小型縦型**（32〜43型）と**駅構内**に限ります。
2. 夜間の輝度上限を設け、点滅や激しい動きは禁止します。静止画中心で、切替はクロスフェードにします。
3. 枠や筐体は元町のサイン計画の色・素材（真鍮色・木目など）に合わせます。
4. 協定の事前協議に、第三者デザイン審査（御堂筋型）を組み込みます。
5. 歩行者天国やセール期間だけの**仮設**として社会実験を行い、データを取ってから常設を判断します。

```
                └──────────────► 来街者：認知(OOH) → 興味(SNS/取材) → 来街(イベント) → 購買(特典) → 再訪(LINE) ◄─┘
```

**統合キャンペーンの組み立て（T＝開催日）**

| 時期 | 提案者 | 代理店 |
|---|---|---|
| T-90〜60日 | コンセプト、KPI設計、取材リスト作成、LP設計 | 企画確定、IP・謎解き会社の手配、媒体の仮押さえ、警察・道路使用の協議 |
| T-60〜30日 | ティザーSNS、プレスリリース第1弾、加盟店特典の取りまとめ | 制作物、景観協議資料（エスエス会と共同） |
| T-14〜0日 | 取材アテンド、インフルエンサー招待、LINE配信 | 駅DOOH（ホームドア・横浜駅・TOQ）の集中出稿 |
| 会期中 | リアルタイムSNS、UGCの再投稿、混雑情報の配信 | 運営、仮設サイネージ、来場カウント |
| T+30日 | 人流・売上・SNSの効果レポート、次回への提言 | 媒体レポート、制作費の精算 |

**原則**
- KPIはひとつのダッシュボードで一元管理します。
- QRとUTMは媒体別に発行します（駅広告→LP→LINE友だち追加→店頭特典の利用まで追跡）。
- 景観協議は代理店任せにせず、エスエス会が主体で行います。

## 4. チャーミングセールのアップデート方法（伝統はそのままに）

- **現状**：春・秋の年2回、9日間程度の会期で、期間中は歩行者天国になります。約200店が参加し、2012年時点の報道では「毎年30万人以上」とされています（[All About](https://news.allabout.co.jp/articles/o/101419/)、[テレビ東京](https://www.tv-tokyo.co.jp/adomachi/backnumber/20120922/76763.html)、[横浜市観光情報](https://www.welcome.city.yokohama.jp/eventinfo/ev_detail.php?bid=yw8858)）。
- **変えないもの**：名称、時期、歩行者天国、「元町品質の正価セール」という信頼。
- **足すもの**：
  - 夜の時間帯
  - デジタル回遊（LINEスタンプ）
  - 体験（工房・アトリエ公開）
  - 測定（AIカウンタ・売上の前年比較）
  - 駅DOOHによる事前告知
  - 新作の先行予約（セール以外の購買導線）

### 元町向けイベント案（5つ）

1. **「チャーミング・ナイト」**（セール初日の金曜の夜、18〜21時）
   FNO型の夜間延長営業です。各店は限定品と予約受付を用意し、来場を購買につなげます。ストリートピアノや弦楽の生演奏、灯籠風の照明を加えます。駅ホームドアビジョンで事前に告知します。
2. **「元町アーカイブ・ウォーク」**（建築・老舗ツアー＋謎解き）
   創業100年級の老舗や山手の洋館と結ぶ街歩きです。タカラッシュかSCRAPに委託し、キット有料で、協賛店の特典を付けます。Winter Wonder Parkの謎解き（元町は既にルートに入っている）と連携します。
3. **「元町クリスマス・プロムナード」**（11月下旬〜12/25）
   赤レンガ（約124万人）とヨルノヨ（延べ100万人）の来場者を受け止めます。屋台型マーケットではなく、**各店ウィンドウを「アドベントカレンダー」化**し、毎日1店の限定品を出します。LINEスタンプで景品を用意します。
4. **「MOTOMACHI デジタルスタンプラリー × LINE」**（年4回、季節ごと）
   一〜五丁目と仲通りでQRを集めます。購買は不要にして参加しやすくし、購入者には抽選を加算します。AIカウンタで丁目間の回遊を測ります。
5. **「元町○○周年 ストリート・ギャラリー」**（周年企画）
   歩行者天国の日に、古写真とアーカイブ映像を**期間限定の仮設サイネージ**で展示します。景観協議を経て、低輝度・静止画中心で行う社会実験とし、常設の判断材料にします。取材誘致の核にもします。
