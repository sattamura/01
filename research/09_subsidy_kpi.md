### 1-3. 申請時の注意
- 市の補助は**予算上限に達し次第締切**。県の受入環境整備は**先着順**。募集開始の初日に出せるよう準備しておく。

## 2. 効果測定・KPI

### 2-1. KPIツリー案（元町SS向け）

```
KGI：元町の来街者数と商店街売上の維持・増加（前年比 +x%）
├─ ① 来街（人流）
│   ├ 歩行者通行量（定点AIカメラ／人手調査）…平日・休日、チャーミングセール期間
│   ├ 滞在人口・来訪者の居住地・年代（人流データ）
│   ├ 新規来訪者比率・リピート率（人流データ、アンケート）
│   └ 回遊：中華街・山手・みなとみらい方面からの流入（人流データ）
├─ ② 購買
│   ├ 加盟店売上（サンプル店の前年比、組合アンケート）
│   ├ プレミアム商品券・デジタル商品券の利用額と店舗分布
│   └ 客単価・購入点数（協力店のPOS）
├─ ③ 認知・関心（デジタル）
│   ├ ウェブ：セッション数、新規ユーザー、店舗ページ閲覧数、地図・電話のクリック、多言語ページの利用
│   ├ SNS：フォロワー増加、リーチ、保存数、エンゲージメント率、UGC（#元町 等の投稿数）
│   └ 検索：指名検索数（「元町 ショッピング」等、Search Console）
├─ ④ 露出・ブランド
│   ├ メディア掲載件数、雑誌コラボの部数・誌面量、広告換算額（参考値）
│   └ 来街者アンケートの認知経路、NPS、満足度
└─ ⑤ 組織・プロセス
    ├ コンテンツ制作本数、SNS投稿数、取材店舗数（アウトプット）
    └ 参加店舗数、店舗のSNS運用率、空き店舗率
```

### 2-3. 測定設計のポイント
1. **ベースラインを取る**：施策の前（2027年春の申請前）に、チャーミングセール（2月・9月）期間と平常時の通行量・人流をそれぞれ測る。
2. **比較対象を置く**：前年同期比、または近隣の商店街や中華街の推移と比べる（差の差分）。天候と曜日をそろえる。
3. **施策ごとにタグを付ける**：サイネージ・雑誌・SNSのQRに個別のUTMを付け、ウェブ流入と来店クーポンの利用まで追う。
4. **人流データは推計値**：KDDIの「全人口推計」と「延べユーザ数」を区別し、推計ロジックの改定に注意する。
5. **補助金の実績報告に合わせる**：市・県の報告書の様式に合わせて、アウトプット（実施回数・制作物）とアウトカム（来街・売上）を記録しておく。

## 3. ロジックモデル

### 3-1. 作り方（手順）
1. **インパクト（目指す姿）**を先に決める（例：「国内外から選ばれ続ける“上質な散策型ショッピングストリート”としての元町」）。
2. 逆算して**長期アウトカム**（3〜5年）→**中期アウトカム**（1〜3年）→**短期アウトカム**（〜1年）を置く。
3. それを生む**活動**と**アウトプット**（量で測れるもの）を対応づける。
4. 各段階に**指標・測定方法・目標値・測定時期**を一つずつ付ける。
5. **前提と外部要因**（インバウンドの動向、天候、競合施設、みなとみらい側の開発など）を明記する。
- 盛岡市（商店街活性化支援事業）は、活動 → にぎわい創出 → 中心市街地の小売年間販売額という段階をロジックモデルで図示し、年度ごとの目標値を置いている。鹿島市は「活動・産出でプロセス評価、半期ごとにアウトカム評価」と分けている。世田谷区は短期・中長期のアウトカム指標を「ソーシャルインパクト指標」として設定している。

| **中期アウトカム**（1〜3年） | 来街と回遊の増加、新規・若年・訪日客の取り込み、購買の増加 | 通行量（AIカメラ）、人流データの来訪者数と属性、滞在時間、商品券の利用額、協力店の売上前年比、アンケートのNPS |
| **長期アウトカム／インパクト**（3〜5年） | ブランド価値の維持・向上、空き店舗の減少、次の担い手の確保、地域経済への波及 | 空き店舗率、新規出店数、来街者1人あたり消費額×来街者数、表彰の受賞 |

### 3-3. 提案での効果的な示し方
- **1枚の横長フロー図**（左から右へ、インプット→インパクト）に、各箱の下へ「KPI／測定方法／目標値」を小さく添える。審査員がひと目で「お金がどの成果につながるか」を追える形にする。
- **施策ごとに色分け**する（ウェブ＝青、イベント＝橙 など）。どの施策がどのアウトカムに効くかを線で結び、**複数の施策が同じアウトカムに集まる**ことを見せる。
- **測れるものと測れないもの**を分ける。短期は確実に測れるデジタルKPIで実績を示し、中長期は人流と売上で「寄与」を示す。因果関係を言い過ぎない。
- **ベースラインと目標値**を表で示す（現状値 → 1年後 → 3年後）。根拠として前年の公開データ（駅の乗車人員、観光動態調査）を引用する。
- **補助金の評価様式に合わせる**：市・県の実績報告の項目（来街者数、売上、参加店舗数）をKPIに必ず入れる。
- **PDCAの周期**を明記する：月次（デジタル）、セール毎（通行量・人流）、年次（売上・アンケート・空き店舗）。
